# 📊 Institution-Based Attendance Management System

This project delivers a robust, automated system to efficiently track and manage attendance for educational institutions, making processes seamless and user-friendly.

- **Frontend:** HTML, CSS, JavaScript
- **Hosting Platform:** InfinityFree
